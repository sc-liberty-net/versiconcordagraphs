# Elements — Concordagraph (Taxes, Tithes, & Tribute)

Code key: **A** Action · **C** Containment · **M** Communication · **N** Navigation · **S** Selection · **T** Text input · **G** Map
Library: https://claude.ai/artifact/LnnC1x1HFqgLnr92PuLgsp

Codes are permanent. Never renumber; retire instead.

Selectors run against `concordagraph.html` (the page the browser loads, with `wordstudy.js` beside it).
Edits go to `concordagraph.html` outside the `// <corpus>` block, or to `wordstudy/embed.js` for the
passage reading and word study (then `python wordstudy/build.py`); the corpus block is generated by
`build_graph.py` from the CSVs. Rows marked "built on open" are written into the page by script when
a passage, word or dialog opens, so they match nothing on a fresh load; that is expected, not a
broken selector. On a phone the graph and the panel sit below the sidebar, so their views scroll.

## Views

Each view is one extra picture: a fresh load, then its steps in order. A row whose Notes say
`view: <name>` is tagged in that picture; a row with no `view:` is tagged in the main picture
(the fresh load; `main` is reserved, never listed here). Steps, separated by `;`:
`click <css selector>` · `press <key>` · `wait <ms>` · `eval <js expression>` (call the page's own
function; no `;` or `|` inside) · `scroll <css selector> top|bottom|<px>` (scrolls that box) ·
`click-at <x>,<y>` (viewport pixels, last resort). Each step gets 3 seconds.
Overviews run at desktop (1280×900) and phone (375×812). Width says which run a view belongs to:
`all` (or blank), `desktop`, or `phone` (narrower than 768px). Every row needs a picture at both
widths, so a row may carry several tokens; `view: main` keeps it in the main picture as well.
Only when the page itself never shows an element at one width, its Notes say `width: desktop`
(or `width: phone`) and why; the other run lists it under `not_at_width` instead.
