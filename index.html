Versiconcordagraphs

Scriptural concordagraphs. One topic per branch.

A concordagraph is a traversable network of source references. Each node is a locatable citation. Each link names two things: what kind of connection it is, and how much weight the text actually puts behind it.

That second part is the point. A graph that draws every connection the same way launders one reader's speculation into settled reference. Here the distinction is visible on the page, so you can always tell what scripture says from what someone thought about it.

How to read a link

Shared wording
The two passages use the same words.
One cites the other
One passage explicitly invokes the other.
Same idea
A thematic or structural parallel, with no shared wording.

How much weight it carries

The text says it
Stated outright in the passage.
The text supports it
A reasonable reading, but inferred.
Speculation
Constructed by the reader. The text does not link these.

No scripture text here, on any page. These pages carry verse references and summaries written for this project — never the wording of a copyrighted translation. Every reference is verified against a verse index built and kept locally; the index itself is never published. Each reference links out to the chapter on Bible Gateway so you can read it in full.
